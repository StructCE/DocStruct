# Configurações Essenciais do WordPress

## Configurações gerais

As configurações básicas do WordPress afetam aspectos importantes do site, como título, idioma, fuso horário, links, SEO e comportamento geral.

Por isso, elas devem ser revisadas no início e no final de cada projeto.

## Onde mudar as configurações

O caminho principal é:

```text
Painel > Configurações
```

Dentro dessa área, é possível alterar seções como:

- geral;
- escrita;
- leitura;
- mídia;
- discussão;
- privacidade.

Na seção **Geral**, é possível alterar informações como:

- título do site;
- descrição;
- URL;
- e-mail do administrador;
- idioma;
- fuso horário.

## Visibilidade nos mecanismos de busca

A opção **“Evitar que mecanismos de busca indexem esse site”** deve ficar desmarcada em sites de produção.

Se essa opção estiver marcada, mecanismos de busca como o Google podem deixar de indexar o site, prejudicando a visibilidade do projeto.

## Configurações de discussão

O caminho para configurar discussões é:

```text
Painel > Configurações > Discussão
```

Essa área permite configurar comentários, notificações e interações em posts.

É importante verificar se o projeto se beneficia de comentários. Blogs e sites de notícias podem precisar dessa função, enquanto páginas institucionais ou sites de serviços muitas vezes não precisam.

Também é importante avaliar se a moderação automática de comentários deve estar ativada, ajudando a evitar spam, links suspeitos e interações indesejadas.

## Privacidade

O caminho para configurar políticas de privacidade é:

```text
Painel > Configurações > Privacidade
```

Essa página é importante para informar como os dados dos usuários serão coletados e utilizados.

A política de privacidade deve ser revisada de acordo com as necessidades do projeto.

## Cadastro de usuários

O WordPress permite controlar se qualquer pessoa pode se cadastrar no site.

Essa configuração fica em:

```text
Painel > Configurações > Geral
```

Em alguns projetos, como lojas virtuais, pode ser interessante permitir que qualquer pessoa crie uma conta.

Em outros projetos, como blogs institucionais ou sites de apresentação, o cadastro público pode não ser necessário.

Quando a criação de contas é permitida livremente, também é importante definir a função padrão de cada nova conta cadastrada.

## Boas práticas

- Revisar as configurações no início e no final do projeto.
- Definir a página inicial corretamente.
- Verificar se o site deve ser indexado por mecanismos de busca.
- Ativar comentários somente quando necessário.
- Evitar cadastro público sem necessidade.
- Revisar o e-mail do administrador.
- Conferir idioma e fuso horário.
