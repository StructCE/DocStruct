# Páginas no WordPress

As páginas são usadas para organizar o conteúdo fixo do site, como página inicial, contato, loja, login e outras seções importantes.

Elas são indicadas para conteúdos que não mudam com frequência.

## Como criar uma página

O caminho mais comum para criar uma página é:

```text
Painel > Páginas > Adicionar nova página
```

Ao criar uma página, é possível definir informações como:

- título;
- conteúdo;
- URL;
- status;
- visibilidade;
- imagem destacada, dependendo do tema ou plugin utilizado.

## Status da página

O status define a visibilidade e o estado da página dentro do site.

Os principais status são:

- **Rascunho:** a página ainda não aparece para o público.
- **Publicado:** a página está visível para os visitantes.
- **Privado:** a página só pode ser vista por usuários autorizados.
- **Agendado:** a página será publicada automaticamente em uma data específica.

## Edição de páginas

Para editar uma página existente, acesse:

```text
Painel > Páginas > Todas as páginas
```

A edição pode ser feita com o editor padrão do WordPress ou com plugins de edição visual, como o Elementor.

## Boas práticas

- Usar nomes claros para as páginas.
- Evitar criar páginas duplicadas sem necessidade.
- Conferir o status antes de finalizar uma página.
- Verificar a URL da página antes da publicação.
- Testar a visualização da página em desktop e mobile.
