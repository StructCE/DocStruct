# Temas e Aparência no WordPress

## O que são temas?

Temas definem a aparência geral de um site WordPress e controlam como o conteúdo será exibido para o usuário.

Um tema pode determinar elementos como:

- cabeçalho;
- rodapé;
- menus;
- botões;
- fontes;
- cores;
- layout geral das páginas.

O tema fornece a base visual do site, enquanto o administrador define e personaliza o conteúdo presente nesses elementos.

## Temas pagos e gratuitos

Assim como plugins, os temas podem ser gratuitos, pagos ou seguir um modelo misto.

Temas pagos geralmente oferecem:

- mais modelos prontos;
- mais opções de personalização;
- suporte técnico;
- atualizações frequentes;
- recursos avançados.

Ainda assim, temas gratuitos podem ser suficientes para muitos projetos, especialmente quando combinados com um bom planejamento visual.

## Como escolher e instalar um tema

O caminho mais comum para instalar um tema é:

```text
Painel > Aparência > Temas > Adicionar tema
```

Após encontrar o tema desejado, basta instalar e ativar.

O **tema ativo** é o tema que está sendo usado no site no momento. Ele pode ser configurado pelo painel administrativo.

Também é importante remover temas não utilizados, tanto por organização quanto por questões de segurança e armazenamento.

## Identidade visual

Antes de personalizar a aparência do site, é recomendado definir uma identidade visual básica.

Essa identidade pode incluir:

- cores principais;
- cores secundárias;
- fontes;
- logo;
- estilo de botões;
- estilo de menus;
- cabeçalho;
- rodapé.

Ter essas decisões documentadas ajuda a manter o site visualmente consistente.

## Menus

Os menus normalmente são configurados em:

```text
Painel > Aparência > Menus
```

ou, dependendo do tema:

```text
Painel > Aparência > Editor
```

## Compatibilidade com plugins

A escolha do tema deve considerar os plugins que serão utilizados no projeto.

Alguns temas são mais compatíveis com plugins como:

- Elementor;
- WooCommerce;
- plugins de formulário;
- plugins de SEO;
- plugins de tradução.

Temas e plugins incompatíveis podem causar problemas como:

- layouts quebrados;
- elementos desalinhados;
- menus com comportamento incorreto;
- perda de responsividade;
- problemas em páginas criadas automaticamente por plugins.

## Construtores visuais

Plugins como o Elementor permitem criar layouts altamente personalizados. Mesmo assim, o tema continua sendo importante.

Quando um construtor visual é usado, é interessante escolher temas mais simples, leves e flexíveis. Dessa forma, o tema funciona como base geral, enquanto os detalhes visuais são construídos de acordo com o projeto.

## Boas práticas

Algumas boas práticas relacionadas a temas são:

- escolher temas de fontes confiáveis;
- evitar temas abandonados;
- verificar compatibilidade com plugins importantes;
- testar a exibição do site em diferentes tamanhos de tela;
- remover temas não utilizados;
- fazer backup antes de trocar ou alterar o tema;
- documentar o tema utilizado no projeto.

## Como documentar o uso do tema

Uma documentação simples do tema pode conter:

- nome do tema utilizado;
- cores principais;
- fontes;
- estrutura do cabeçalho;
- estrutura do rodapé;
- plugins visuais utilizados;
- observações sobre personalizações.

Após trocar ou alterar um tema, teste se:

- as páginas continuam sendo exibidas corretamente;
- os menus funcionam;
- a responsividade foi preservada;
- o desempenho não foi prejudicado.
