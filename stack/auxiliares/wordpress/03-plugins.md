# Plugins no WordPress

## O que são plugins?

Plugins são pacotes instaláveis que adicionam funcionalidades ao WordPress, expandindo as capacidades do site além da administração básica de conteúdo.

Assim como bibliotecas e pacotes em linguagens de programação, os plugins permitem implementar funcionalidades comuns rapidamente, sem precisar desenvolver tudo do zero.

Alguns tipos populares de plugins são:

- cache;
- construção visual;
- formulários;
- segurança;
- backup;
- pagamentos;
- SEO;
- lojas virtuais.

## Como instalar um plugin

O caminho mais comum para instalar um plugin é:

```text
Painel > Plugins > Adicionar novo plugin
```

É importante lembrar que **instalar** e **ativar** um plugin são ações diferentes.

- **Instalar** adiciona os arquivos do plugin ao site.
- **Ativar** faz com que o plugin comece a funcionar.

Depois de ativado, alguns plugins começam a funcionar automaticamente. Outros exigem configuração para exercer sua função corretamente.

## Como escolher um plugin

A escolha de um plugin deve considerar tanto a funcionalidade oferecida quanto a segurança e a manutenção do pacote.

Antes de instalar um plugin, verifique:

- se ele resolve a necessidade do projeto;
- se possui boas avaliações;
- se vem de uma fonte confiável;
- se recebe atualizações recentes;
- se possui histórico aceitável de segurança;
- se é compatível com o tema e com os outros plugins do site;
- se é gratuito, pago ou possui modelo misto.

Evite instalar plugins que resolvem apenas parte do problema, pois isso pode levar à instalação de vários plugins complementares. Com o tempo, o excesso de plugins dificulta a manutenção e aumenta o risco de conflitos.

## Boas práticas

Para instalar, alterar ou remover plugins em um projeto, siga algumas boas práticas:

- verificar se o plugin é realmente necessário;
- analisar questões de segurança, fonte e atualizações;
- manter uma lista dos plugins instalados e suas funções;
- fazer backup antes de adicionar ou remover plugins importantes;
- testar o site após alterações;
- evitar plugins com funções duplicadas;
- remover plugins inúteis ou abandonados.

Plugins que tratam das mesmas funções podem entrar em conflito. Por isso, o ideal é manter apenas um plugin para cada necessidade principal.

Além disso, plugins desativados ainda ocupam espaço e podem representar riscos de segurança. Quando não forem mais úteis, devem ser removidos do projeto.
