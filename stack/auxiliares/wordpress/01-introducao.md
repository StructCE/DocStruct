# Introdução ao WordPress

## O que é WordPress?

O WordPress é uma ferramenta para criar e gerenciar sites de maneira rápida. Ele é um **CMS** (*Content Management System*), ou seja, um sistema de gerenciamento de conteúdo.

Ao contrário de frameworks como Next.js, Django e Laravel, o WordPress não é uma linguagem de programação nem exige que o projeto seja construído escrevendo código da maneira tradicional. Em vez disso, grande parte do trabalho é feita por meio de um painel administrativo.

Por sua facilidade de uso, o WordPress é frequentemente usado para criar:

- blogs;
- portfólios;
- landing pages;
- sites institucionais;
- sites de notícias;
- lojas virtuais.

Como não é necessário escrever tanto código, projetos em WordPress podem ser executados de forma mais rápida e simples. Em troca, existe menos controle técnico em comparação com projetos desenvolvidos diretamente com uma linguagem de programação ou framework próprio.

## Como o WordPress funciona?

Em vez de criar e editar arquivos de código manualmente, o responsável pelo site utiliza um **painel administrativo** para gerenciar os principais componentes do projeto.

Dentro do painel, é possível manipular elementos como:

- aparência do site;
- páginas;
- posts;
- usuários;
- plugins;
- temas;
- configurações gerais.

## Plugins

Plugins são pacotes instaláveis que adicionam funcionalidades ao WordPress de maneira rápida.

Eles funcionam de forma parecida com bibliotecas ou pacotes usados em programação: permitem adicionar recursos prontos sem precisar desenvolver tudo do zero.

Existem plugins gratuitos, pagos e também plugins com modelo misto, em que algumas funções são gratuitas e outras exigem pagamento.

## Temas

Um tema controla a aparência geral do site, como layout, cabeçalho, fontes, menus e rodapé.

O tema define a base visual do site, mas o conteúdo e muitos detalhes de aparência ainda podem ser personalizados pelo administrador ou desenvolvedor.

## Páginas

As páginas são usadas para organizar seções fixas do site, geralmente com conteúdos que não mudam com frequência.

Exemplos comuns de páginas são:

- página inicial;
- loja;
- login;
- minha conta;
- contato;
- sobre.

## Posts

Posts são usados para conteúdos atualizados ou adicionados com mais frequência, como notícias, anúncios, artigos e publicações de blog.

Eles também podem ser organizados por categorias e tags.

## Usuários

O WordPress possui um sistema nativo de usuários, que permite criar contas com diferentes níveis de permissão.

Algumas funções comuns são:

- administrador;
- editor;
- autor;
- colaborador;
- assinante;
- cliente, quando plugins como WooCommerce são utilizados.
