# Editor Padrão do WordPress e Elementor

## Editor padrão do WordPress

O editor padrão do WordPress é a ferramenta nativa usada para criar e alterar páginas e posts.

Os caminhos mais comuns para acessar o editor são:

```text
Painel > Páginas > Adicionar nova página
```

ou:

```text
Painel > Páginas > Todas as páginas > Editar
```

Esse editor é suficiente para criar páginas simples, posts, textos e layouts que não exigem muita complexidade visual.

## Blocos

O editor padrão funciona com um sistema de blocos. Cada parte do conteúdo é organizada em um bloco separado.

Alguns blocos comuns são:

- parágrafo;
- título;
- imagem;
- lista;
- botão;
- tabela;
- vídeo;
- citação.

Esse sistema permite montar conteúdos de forma organizada, sem precisar escrever código.

## Quando usar o editor padrão

O editor padrão funciona bem para conteúdos simples e médios, como:

- posts;
- notícias;
- páginas institucionais;
- textos informativos;
- páginas com layout simples.

As principais vantagens são:

- é mais leve do que editores visuais complexos;
- não depende de plugins externos;
- é nativo do WordPress;
- costuma ser mais simples de manter.

As principais limitações são:

- menor controle visual;
- menos opções avançadas de personalização;
- maior dificuldade para criar layouts muito elaborados.

## Elementor

O Elementor é um dos plugins de edição visual mais populares para WordPress.

Ele permite criar páginas usando uma interface visual de arrastar e soltar (*drag and drop*), oferecendo maior controle sobre o layout e a aparência da página.

## Estrutura do Elementor

O Elementor organiza a página usando alguns conceitos próprios.

Os principais são:

- seções;
- containers;
- colunas;
- widgets;
- templates.

## Seções e colunas

As seções representam áreas principais da página. Elas funcionam como blocos maiores que agrupam elementos menores.

Exemplos de seções:

- seção de apresentação;
- seção de produtos;
- seção de contato;
- seção de depoimentos.

As colunas ajudam a organizar elementos internamente dentro de uma seção ou container.

## Widgets

Widgets são os elementos que compõem a página, de forma parecida com os blocos do editor padrão do WordPress.

Alguns exemplos de widgets são:

- título;
- texto;
- imagem;
- botão;
- formulário;
- ícone;
- vídeo.

Cada widget possui configurações próprias de conteúdo e estilo.

## Templates

Templates são modelos prontos e reutilizáveis.

Alguns exemplos são:

- página inicial;
- seção de contato;
- card de produto;
- bloco de chamada para ação.

Templates são úteis para padronizar o design e reduzir o tempo necessário para construir novas páginas.

## Onde editar uma página com Elementor

O caminho mais comum é:

```text
Painel > Páginas > Todas as páginas > Editar com Elementor
```

## Conteúdo, estilo e avançado

Cada elemento do Elementor possui três áreas principais de configuração:

- **Conteúdo:** controla as principais informações do elemento, como texto, link e ícone.
- **Estilo:** controla a aparência, como cor, fonte, tamanho e fundo.
- **Avançado:** controla aspectos mais específicos, como margem, responsividade, ID e classes CSS.

## Boas práticas com Elementor

O Elementor oferece bastante liberdade para manipular páginas. Porém, sem cuidado, isso pode resultar em páginas desorganizadas e difíceis de manter.

Algumas boas práticas são:

- evitar excesso de widgets;
- reutilizar estilos;
- dar nomes significativos aos elementos;
- testar o layout em desktop e mobile;
- manter um estilo visual consistente em todo o site;
- prestar atenção ao desempenho da página;
- evitar plugins extras para Elementor quando possível;
- evitar layouts complexos sem necessidade;
- fazer backup antes de grandes alterações;
- testar as páginas após alterações.
