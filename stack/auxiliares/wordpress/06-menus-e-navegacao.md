# Menus e Navegação no WordPress

## O que são menus?

Menus são grupos de links exibidos em áreas específicas do site, geralmente no cabeçalho, no rodapé ou em áreas laterais.

Eles são essenciais para oferecer uma experiência de navegação simples, rápida e intuitiva para o usuário.

## Onde configurar menus

O caminho mais comum para alterar menus é:

```text
Painel > Aparência > Menus
```

Em alguns temas mais recentes, a configuração também pode estar em:

```text
Painel > Aparência > Editor
```

É importante lembrar que criar uma página não significa que ela será adicionada automaticamente ao menu. Normalmente, é necessário adicioná-la manualmente.

## Itens de menu

Os itens mais comuns em um menu são:

- páginas;
- posts;
- produtos;
- carrinho;
- conta;
- links personalizados;
- categorias.

Também é possível usar submenus, o que é útil para sites com páginas relacionadas.

## Boas práticas para menus

- Manter o menu curto e objetivo.
- Evitar submenus muito profundos.
- Testar o menu em diferentes telas, como desktop e mobile.
- Verificar se todos os links personalizados funcionam corretamente.
- Usar nomes claros para os itens do menu.
- Priorizar as páginas mais importantes do site.
